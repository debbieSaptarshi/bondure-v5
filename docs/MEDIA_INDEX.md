# Media Index

Use this index to locate visual assets without searching source code. All file names use lowercase kebab-case and identify the page or section first where practical.

## Naming Rules

- Store page-only files in the folder for that page or section.
- For a new image used on more than one page, create a copy in each relevant page folder and prefix it with the page or section name.
- Use descriptive names: `[page]-[section]-[subject].[extension]`.
- Do not use spaces, capital letters, copy markers such as `(1)`, or generic names such as `image-1`.
- Update every matching path in code when a file is renamed.
